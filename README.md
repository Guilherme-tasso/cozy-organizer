# Cozy Organizer

Joguinho de organizar a casa junto com o Biscoito, um gato. Cada objeto guardado no lugar certo libera uma memória para o álbum.

Feito em um único arquivo HTML, com CSS e JavaScript puro.

## Como rodar

Basta abrir o `index.html` no navegador.

## Como jogar

- Arraste cada objeto até a categoria certa, ou toque no objeto e depois na categoria
- No teclado, as teclas 1 a 5 guardam o objeto selecionado
- Travou? Clique no Biscoito para pedir uma dica
- Arrume a Sala, o Quarto e depois a Casa Toda
- "Nova bagunça" sorteia outros objetos

## O que tem

- Álbum de memórias com tudo o que já foi encontrado
- Recorde de tempo por cômodo
- Sons, tema claro/escuro e suporte a toque
- Progresso salvo no `localStorage`
